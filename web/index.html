Local storage

          
          
Save snapshots and blocked records by account and channel for offline search after restarting. Disabling this deletes messages from disk; the current list remains available.

          
          
Login is protected by macOS Keychain or Windows current-user encryption. Codes and two-step passwords are never saved. Disabling this deletes the saved login while keeping the current session active.

          
This feature requires core 1.5.0.
