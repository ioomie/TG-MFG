# TG-MFG · Windows guide

[English README](README.md) | [中文 README](README.zh-CN.md)

> **Only macOS and Windows clients are supported. All project code was entirely generated by AI.**

## Install

1. Download `TG-MFG-Windows-x64.zip` and fully extract the `TG-MFG` directory. Do not run from inside the ZIP.
2. Double-click `install.bat`. It installs to `%LOCALAPPDATA%\TG-MFG`, registers the current-user `tg-mfg://start` launcher and starts the core. The package includes official Python 3.13.16 x64 and pinned dependencies. Python, pip and administrator access are not required.
3. Open the website or `http://127.0.0.1:8765` if the browser did not open. Enter your Telegram API ID / Hash and sign in.

Supports Intel / AMD 64-bit Windows 10 / 11. No 32-bit or native ARM64 package is provided. The runtime needs no dependency download; Telegram login and fetching still require network access.

Once installed, the installation window can close. The website reconnects to a running core. A remembered installation marker allows one launch attempt; if the browser blocks it, click **Start core** and allow TG-MFG to open. The marker contains no account data and has no application-defined expiry. It is not proof that the files still exist.

Keep the installed user directory in place; the original extracted download may be removed. Reinstallation stops the matching installation, replaces its code and preserves opted-in local data. It does not stop another installation. **Stop core** exits the service. Closing the browser does not stop it. No boot-time auto-start is configured.

## Proxies and diagnostics

Before connecting, enable SOCKS5 or HTTP CONNECT and enter the port your proxy actually listens on. For example, `127.0.0.1:7890` works only if that port supports the chosen protocol. Core 1.2.1 introduced asynchronous `python-socks` handshakes for Windows; failure never falls back to a direct connection.

Use **Connection diagnostics → Test proxy settings** to test the handshake and Telegram TCP tunnel before login. This requires no API credentials and does not verify account login. Timeouts return 504, network/proxy failures 503 and invalid parameters 400.

A successful core check verifies the local API, not Telegram connectivity. Download from the same website origin you intend to use so its core package contains the correct allowed origin. Allow browser local network access if prompted.

Enable core debug logging, retry the failure and export `TG-MFG-diagnostics.json`. If the website cannot enable logging, run `debug.bat` in the download package. It operates on the managed installation rather than starting another core.

Logs: `%LOCALAPPDATA%\TG-MFG\debug.log`; startup output: `startup.log` in the same directory. Diagnostics keep the latest 200 structured events and about 512 KiB of rotated disk logs. Bodies, keys, phone numbers, codes, passwords, tokens and message content are excluded. Review proxy hosts and website origins before sharing. Logging resets on restart; raw Telethon logging is not enabled. Launcher health checks bypass system HTTP proxies.

## Manual source mode

The source archive does not include Python. Install Python 3.9+ from the [official website](https://www.python.org/downloads/windows/), then run `run.bat`. It creates `.venv` and installs pinned, hash-verified PyPI dependencies. Keep its terminal open.

For an occupied port:

```bat
run.bat --port 8767
```

This option applies to manual mode. The managed website launcher uses port 8765. `127.0.0.1` always means the current computer, so the core must run on that Windows computer.

## Local storage

Both storage switches are off by default. Messages and blocked records are saved in `%LOCALAPPDATA%\TG-MFG\data\messages.sqlite3` without encryption. Saved login in `login.bin` is encrypted with current-user DPAPI; it cannot simply be copied to another user. Login codes and two-step passwords are never saved. Restarting restores opted-in data and the saved proxy; offline search works without login. Update checks require a connection and check existing IDs without fetching new messages.

**Disconnect & clear** deletes saved data and attempts Telegram logout. If not confirmed, remove the session in the official app under Devices. See the [README](README.md) for fetch reports, storage and update semantics.

## Runtime provenance and validation

The package uses [official CPython 3.13.16](https://www.python.org/downloads/release/python-31316/), verified against the pinned SHA-256 in [BUILD.md](docs/BUILD.md). `BUILD-INFO.json` and bundled licenses record its provenance and dependency versions.

Build integrity and offline behavior have been tested on the development machine. Native Windows registration, launching, DPAPI and proxy behavior still require Windows testing before a stable installer release.
